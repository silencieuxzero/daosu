平面主义（Flat Design）常常被误读为"偷懒的设计"——没有渐变、没有阴影、没有材质，看起来谁都能做。

但它的源头并不简单。二十世纪中叶，瑞士国际主义把排版变成了科学：网格系统、无衬线字体、严格的对齐关系。平面主义继承了这份遗产，又把数字时代的冗余剥掉了一层。

## 平面主义的三条规则

如果要用三句话概括这个主题的设计逻辑：

1. **无阴影**——物体不需要从背景中"浮起来"，它就在那里
2. **粗边框**——用 2px 实线划定疆域，比任何投影都诚实
3. **纯色填充**——一个颜色就是一块信息，混色只会稀释它

> 设计不是装饰，而是信息的秩序。去掉一切阴影之后，剩下的形状与颜色才真正说话。

## 与 CSS 变量的关系

这套主题的全部秘密都藏在变量里：

```css
[data-theme='modern'] {
  --bg: #ffffff;
  --fg: #0a0a0a;
  --accent: #0000e0;
}

[data-theme='ancient'] {
  --bg: #2e3b52;
  --fg: #f2f2ff;
  --accent: #ffffff;
}
```

切换主题不是重做设计，只是换一组值。现代与古代共用同一套组件、同一种排版语言——**气质变了，语法没变**。这是我认为平面主义最适合做主题系统的原因。

## 为什么是黑白灰与黛蓝

| 主题 | 主色调 | 性格 |
|------|--------|------|
| 现代 | 黑白灰 | 冷静、精确、工业感 |
| 古代 | 黛蓝 #2E3B52 | 苍古、沉静、低饱和 |

黑白灰是"无色彩"的诚实，黛蓝是"单色彩"的克制。两者都拒绝花哨，这正是它们能共存于一套主题里的原因。
